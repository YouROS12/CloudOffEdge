# paper — manuscript sources

Elsevier `elsarticle` source for *Results in Engineering*.
`main.pdf` is the compiled manuscript; `main.docx` a Word version built from the same
source.

- `main.tex` — manuscript.
- `numbers.tex` — every measured value as a LaTeX macro (`\R...`), generated by
  `experiments/scripts/make_paper_numbers.py` from `results/` and `artifacts/`.
  Never edit by hand; re-run the script.
- `refs_paper1.bib`, `refs_edge.bib` — bibliography, checked against Crossref,
  DataCite and OpenAlex.
- `figures/` — generated by `experiments/scripts/make_paper_figures.py`
  (`fig_console.jpg` is a screenshot of `experiments/console`). The three diagrams
  (system overview, architecture, porting pipeline) are TikZ code inside `main.tex`.

Build:

```bash
python experiments/scripts/make_paper_numbers.py
python experiments/scripts/make_paper_figures.py --fleet-run results/fleet_run
tectonic -X compile paper/main.tex        # or pdflatex/bibtex, or Overleaf
python experiments/scripts/make_docx.py   # Word version (pypandoc_binary, tectonic)
```

Journal limits (Guide for Authors): abstract ≤ 250 words, 3–5 highlights of ≤ 85
characters, 1–7 keywords.
